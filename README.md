# Jira-Einführungs-Playbook

Ein praxisnahes Handbuch, um Jira Software und Jira Service Management (JSM) in Unternehmen einzuführen – von der ersten Kundenanfrage bis zum laufenden Betrieb.

**Ziel:** Jede Einführung läuft nach demselben, erprobten Ablauf. Vorlagen, Checklisten, Automations-Rezepte und Skripte liegen griffbereit, damit Integrationen schnell und sauber umgesetzt werden.

> Stand: Oktober 2026. Preise, Limits und Fristen von Atlassian ändern sich regelmäßig – vor jedem Angebot auf atlassian.com prüfen.

## So nutzt du das Playbook

1. **Neuer Kunde?** → [Discovery-Checkliste](02-discovery-checkliste.md) durchgehen und [Angebot](vorlagen/angebot-pakete.md) anpassen.
2. **Projekt startet?** → [Vorgehensmodell](01-vorgehensmodell.md) folgen und [Kickoff-Agenda](vorlagen/kickoff-agenda.md) nutzen.
3. **Konfiguration?** → Kapitel 03–06 als Bauanleitung, [Konzept-Vorlage](vorlagen/konzept.md) ausfüllen.
4. **Integration nötig?** → [Integrationen](07-integrationen.md) + [Skripte](scripts/).
5. **Go-Live?** → [Go-Live-Checkliste](vorlagen/go-live-checkliste.md) und [Abnahmeprotokoll](vorlagen/abnahmeprotokoll.md).
