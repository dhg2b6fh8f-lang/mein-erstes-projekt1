# Go-Live-Checkliste

## Konfiguration
- [ ] Alle Workflows mit Test-Nutzer (ohne Admin-Rechte) durchgespielt
- [ ] Jeder Done-Status setzt die Lösung
- [ ] Pflichtfelder und Validatoren funktionieren
- [ ] Boards/Queues zeigen die richtigen Vorgänge
- [ ] Benachrichtigungen geprüft (Testmail kommt an, keine Mail-Flut)
- [ ] Automationen aktiv, Audit-Log ohne Fehler
- [ ] Dashboards für jede Zielgruppe vorhanden

## JSM
- [ ] Portal aus Kundensicht getestet (eigener Test-Kundenaccount)
- [ ] E-Mail-Kanal: Testmail erzeugt Ticket, Antwort kommt beim Kunden an
- [ ] SLAs laufen mit richtigem Kalender
- [ ] Wissensdatenbank verknüpft
- [ ] Wer darf Tickets stellen? (Domains, Organisationen)

## Berechtigungen & Sicherheit
- [ ] Alle Nutzer angelegt und in den richtigen Gruppen
- [ ] Sicherheitsstufen getestet
- [ ] Kein ungewollter anonymer Zugriff
- [ ] SSO/2FA aktiv (falls vereinbart)

## Daten
- [ ] Migration durchgeführt, Stichproben vom Fachbereich bestätigt
- [ ] Altsystem auf „nur lesen“ bzw. Umleitung eingerichtet

## Menschen
- [ ] Schulungen durchgeführt
- [ ] Spickzettel verteilt
- [ ] Champions benannt
- [ ] Ankündigung an alle (Was ändert sich ab wann? Wo gibt es Hilfe?)
- [ ] Hypercare-Sprechstunde terminiert

## Übergabe
- [ ] Betriebshandbuch übergeben
- [ ] Jira-Owner kennt Governance-Regeln
- [ ] Abnahmetermin vereinbart
