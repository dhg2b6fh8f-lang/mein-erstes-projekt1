# Checkliste vor dem Livegang

## Recht
- [ ] Impressum vollständig: Vor- und Nachname, Anschrift, E-Mail, Telefon, ggf. USt-IdNr./W-IdNr.
- [ ] Datenschutzerklärung (Hosting, Logfiles, Kontakt, alle Dienste)
- [ ] Schriften **lokal** eingebunden, keine externen Skripte ohne Einwilligung
- [ ] Kein Tracking ohne Einwilligung (oder gar keins)
- [ ] HTTPS aktiv
- [ ] Auftragsverarbeitungsvertrag mit Hoster
- [ ] Hinweis „Angebot ausschließlich für Unternehmen“
- [ ] Bildrechte geklärt, Freigaben für Logos/Zitate
- [ ] Hinweis „Jira ist eine Marke von Atlassian“

## Inhalt
- [ ] Echtes Porträtfoto eingesetzt
- [ ] Alle Platzhalter ersetzt
- [ ] Preise geprüft
- [ ] Keine erfundenen Zahlen oder Kundenstimmen
- [ ] Rechtschreibung geprüft, keine toten Links
- [ ] LinkedIn verlinkt

## Technik
- [ ] Mobil getestet (Handy, Tablet)
- [ ] Hell- und Dunkelmodus geprüft
- [ ] PageSpeed Insights: Core Web Vitals grün
- [ ] Titel und Beschreibung gesetzt, Vorschaubild für Teilen (Open Graph)
- [ ] Favicon
- [ ] Eigene Domain + E-Mail-Adresse eingerichtet

## Nach dem Start
- [ ] Google Search Console einrichten, Seite einreichen
- [ ] Google-Unternehmensprofil anlegen
- [ ] Link in LinkedIn-Profil, E-Mail-Signatur, Briefbogen
- [ ] Ersten Artikel planen
