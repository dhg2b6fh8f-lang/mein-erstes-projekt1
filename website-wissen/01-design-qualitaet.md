# 01 – Professionell statt billig

## Erkennungszeichen einer „billigen“ KI- oder Template-Seite
| Merkmal | Besser |
|---|---|
| Indigo-/Lila-Farbverlauf auf Weiß (gilt 2026 als auffälligstes KI-Merkmal, stammt aus Standard-Farben gängiger CSS-Frameworks) | Eigene, schmale Palette: eine Markenfarbe + abgestimmte Neutraltöne |
| Inter, Roboto oder Arial ohne bewusste Entscheidung | Bewusst gewähltes Schriftpaar mit Charakter |
| Zentrierter Hero mit „Get Started“ + drei gleiche Icon-Karten mit Schatten | Layout aus dem Inhalt ableiten: Beispiele, Abläufe, echte Arbeit zeigen |
| Austauschbare Sprüche („Innovative Lösungen für Ihr Business“) | Zielgruppe + konkretes Ergebnis, das nur wir so sagen |
| Stockfotos lachender Menschen im Büro | Echtes Porträt, Fotos aus Workshops, anonymisierte Screenshots echter Ergebnisse |
| Formulare ohne Fehlermeldungen und Pflichtfeld-Kennzeichnung | Beschriftete Felder, verständliche Fehlertexte, Bestätigung |
| Animationen überall | Sparsam, gezielt, Rücksicht auf „Bewegung reduzieren“ |
| Erfundene Zahlen, „100 % Erfolgsquote“, unbelegte Logos | Nur echte, nachprüfbare Angaben |

**Belege:** Laut Eye-Tracking-Studien der Nielsen Norman Group übersehen Nutzer generische Stockfotos von Menschen, schauen Fotos echter Personen aber intensiv an – in einer Studie länger als die viel größeren Textblöcke daneben.

## Prinzipien guten Designs
- **Typografie:** Fließtext mindestens 16 px, Zeilenlänge etwa 45–75 Zeichen, Zeilenabstand großzügig. Echte Anführungszeichen „…“ und Gedankenstriche –.
- **Farbe:** Wenige Farben mit klarer Aufgabe (Akzent nur für Wichtiges/Aktionen). Kontrast mindestens 4,5:1 für normalen Text, 3:1 für großen Text.
- **Weißraum & Raster:** Einheitliche Abstände, klare Hierarchie (eine H1, dann H2/H3).
- **Konsistenz:** Farben, Abstände, Radien als feste Werte (Design-Tokens). Gleiche Elemente sehen überall gleich aus.
- **Mikrotexte:** Konkrete Buttons („30-Minuten-Gespräch vereinbaren“ statt „Mehr erfahren“).
- **Glaubwürdigkeit** (nach Nielsen Norman Group): fehlerfreies Design, Offenheit bei Preisen und Bedingungen, aktuelle Inhalte, externe Bestätigung (LinkedIn, Bewertungen, Zertifikate).

## Technische Qualität
| Kennzahl (Core Web Vitals) | Gut |
|---|---|
| LCP – Ladezeit des größten Elements | ≤ 2,5 s |
| INP – Reaktion auf Eingaben | ≤ 200 ms |
| CLS – Layout-Verschiebung | ≤ 0,1 |

- Mobil zuerst denken, kein seitliches Scrollen, große Tippflächen
- Barrierefreiheit: Kontraste, Alt-Texte, sichtbarer Fokus, Tastaturbedienung
- SEO-Grundlagen: eigener Titel und Beschreibung pro Seite, sinnvolle Überschriften, sprechende Adressen
- Bilder als WebP/AVIF mit festen Maßen

## Checkliste: professionell vs. billig (25 Punkte)
1. Überschrift nennt Zielgruppe und Ergebnis
2. Kein Lila-Verlauf, keine Standardfarben
3. Maximal eine Akzentfarbe
4. Bewusste Schriftwahl, Fließtext ≥ 16 px
5. Kein Raster aus drei gleichen Icon-Karten als Hauptinhalt
6. Echtes Porträt, keine Stock-Menschen
7. Echte Arbeitsproben (anonymisiert)
8. 2–3 Fallbeispiele mit Problem, Vorgehen, Ergebnis
9. Referenzen nur mit Freigabe, mit Name und Funktion
10. Leistungen konkret, mit Ablauf und Preisrahmen
11. Ein klarer Haupt-Button mit konkretem Text
12. Formulare mit Beschriftung und Fehlermeldungen
13. Impressum und Datenschutz vollständig
14. Keine Tippfehler, keine toten Links
15. Einheitliche Abstände, Radien, Schatten
16. Sparsame Animation, „Bewegung reduzieren“ respektiert
17. Core Web Vitals im grünen Bereich
18. Bilder optimiert
19. Kontrast ≥ 4,5:1, sichtbarer Fokus
20. Alt-Texte, logische Überschriften
21. Titel und Beschreibung pro Seite
22. Mobil getestet
23. Aktuelle Inhalte mit Datum
24. Externe Belege verlinkt (LinkedIn, Zertifikate)
25. Eigene Domain, eigene E-Mail, HTTPS
